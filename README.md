# Lega1Assistant
Помощник юриста на базе ИИ
Чтобы убрать зачёркнутую строку "README":

Создай файл README.md в корне своего репозитория, если его там ещё нет.
Напиши внутри файла хотя бы минимальный текст, например:

# Lega1Assistent
Помощник юриста на базе ИИ.

Загрузи этот файл в репозиторий командой:

git add README.md
git commit -m "Создан файл README.md"
git push origin main

Теперь строка должна стать нормальной.
